# 백엔드 전체 장애 대응: 정적 스냅샷

백엔드가 완전히 내려가도 72개 지역의 진단과 예산 시뮬레이션을 이어 가기 위한 구조를 적는다. 추정 계산 규칙과 서버 비교는 [estimated-simulation.md](estimated-simulation.md)에 있다.

## 현재 상태

| 항목 | 상태 |
|---|---|
| 코드(로더 · 전환 · 복구 · 화면) | 저장소에 있음 |
| 72개 지역 자료 | **저장소와 배포에 없음.** `snapshot.local/`(Git 제외)에만 있다. 이용 조건을 확인하지 못한 자료가 있어서다(5절) |
| 지금 운영 배포의 동작 | 정적 파일이 없으므로 전체 장애 때 오류 안내를 보여 준다. 기존 동작과 같다 |

공개 여부는 5절의 확인과 판단이 끝난 뒤에 정한다. 지금 코드는 지역별 통합 파일을 읽는다. OSM 값을 별도 파일로 나눠 공개하기로 하면 수집 스크립트와 로더를 고쳐야 한다.

## 1. 상황별 동작

| 상황 | 지역 자료 | 계산 | 화면 표시 |
|---|---|---|---|
| 서버 정상 | 서버 | 서버 | 장애 안내 없음. 정적 파일을 받지 않는다 |
| 계산 API만 장애 | 서버 | 브라우저 추정 | `자료: 서버 자료 · 계산: 브라우저 추정` + 추정 안내 |
| 지역 자료 API만 장애 | 정적 파일 | 서버 | `자료: 저장된 정적 자료(수집일) · 계산: 서버 계산` |
| 지역 목록 API만 장애 | 서버 | 서버 | 목록만 정적 파일, 지역을 고르면 서버 자료 |
| 경계 API만 장애 | 서버 + 저장한 경계 | 서버 | 안내 없음 |
| 백엔드 전체 장애 | 정적 파일 | 브라우저 추정 | `자료: 저장된 정적 자료(수집일) · 계산: 브라우저 추정` + 추정 안내 |
| 정적 파일도 없거나 손상 | 없음 | 없음 | 오류 안내. 값을 만들지 않는다 |

## 2. 파일 구조

```
public/data/snapshot/        (배포 위치. 공개 승인 전에는 비어 있다)
  manifest.json              처음에 받는 파일. 약 60KB(전송 약 11KB)
  48740.json ...             지역 하나당 하나. 고를 때 받는다
```

**manifest.json**: `schema` · `dataVersion` · `capturedAt`(수집일) · `origin` · `complete` · `totalRegions` · `totalVillages` · `tiers` · `regions`(서버 `/api/regions`와 같은 모양) · `defaultState` · `files`(지역별 경로 · 크기 · gzip 크기 · SHA-256 · 마을 수 · 상태 · 지표) · `sources`(출처 · 주소 · 기준 시점 · 쓰는 지역 수)

**지역 파일**: `{ data, map, notes }`. `data` · `map`은 서버 응답과 값이 같고, `notes`는 서버 레포트 각주의 출처와 기준 시점이다. `capturedAt`은 수집일이고 원본 자료의 시점은 `notes[].date`에 자료별로 있다.

**저장하지 않는 칸**: 앱이 읽지 않는 칸은 뺀다(`scripts/snapshot-check.mjs`의 `stripRegion`). `nearest.school`, `nearest.library`, `myeons[].pharmacy`, `bus.dailyRunsBis`, `indicators.runsShareBis`. 나머지 값은 바꾸지 않는다.

**읽을 때 검사**(`src/api/snapshot.ts`): HTML 응답 거부(없는 파일에 SPA 첫 화면이 200으로 온다), JSON 파싱, SHA-256 대조(보안 컨텍스트), 지역 코드 · 이름 · 등급 · 마을 수 일치, 마을 칸 검사(`validRegionData`), 경계 형식. 하나라도 틀리면 그 파일을 쓰지 않고 오류를 보여 준다. 실패는 기억하지 않아 다음에 다시 받는다. 성공한 파일은 페이지 안에서 다시 받지 않는다.

## 3. 장애 감지와 전환

- **바로 실패하는 장애**(연결 실패 · 5xx · 잘못된 응답): 요청이 곧바로 실패하므로 각 요청이 정적 자료 · 추정으로 넘어간다. 기다림이 없다.
- **답 없이 멈춘 서버**: 지역 목록 · 자료 요청이 `GRACE_MS`(4초) 안에 답하지 않으면 정적 자료를 먼저 보여 주고, 판정 · 대안 · 지역 자료를 60초 동안 장애로 기억한다(`markHung`). 그동안 계산은 서버를 부르지 않고 바로 추정한다. 늦게라도 답이 오면 서버 값으로 바꾼다.
- 카드 72개가 지역 파일 72개를 받지 않도록, 지역 카드의 지표는 manifest에서 읽는다.

## 4. 복구

- **버튼**: '서버로 다시 계산' · '서버 다시 확인'은 `retryServer`를 부른다. 먼저 `/api/health`를 4초 안에 묻고, 연결이 안 되면 다른 API를 부르지 않고 값을 그대로 둔다.
- **자동**: 저장 자료나 추정을 쓰는 동안만 60초마다, 탭으로 돌아왔을 때, 네트워크가 다시 붙었을 때 `recheckServer`가 `/api/health`만 묻는다. 정상 상태에서는 아무것도 부르지 않는다.
- **전환**: 받기 전에 화면을 비우지 않는다(`refreshRegion`). 받은 자료가 저장본과 같으면 객체를 그대로 둬 지도와 입력이 움직이지 않고, 다르면 옛 자료로 만든 판정 · 대안을 버리고 새 자료로 다시 계산한다.
- **유지되는 것**: 지역 · 예산 · 목표 · 공급수단 · 단가 · 고른 안 · 바꿔 본 What-if 예산.
- 복구 요청은 `cache: 'no-store'`로 보내, 멈춘 요청이 쥔 HTTP 캐시 잠금과 캐시된 옛 응답을 피한다.

## 5. 데이터 이용 조건 (2026-11-06 확인)

**공개 후보는 OSM 관련 조건이 해결된다는 전제에서 28곳이고, 그 전까지 공개할 수 있는 지역은 0곳이다.** 이 절은 법률 검토가 아니다. 페이지 표시와 백엔드 기록을 옮긴 것이고, 공개 여부는 팀이 결정한다.

### 확정된 사실

페이지나 데이터에서 직접 확인한 내용이다.

**OSM 유래 값**

- 마을 좌표 7,916곳 중 **5,007곳(63%, 64개 지역)이 OSM 마을 지점 좌표**다. 나머지는 경로당 좌표 2,875곳, 수기 지정 34곳이다. 백엔드 산출물의 `locSource`를 72개 지역 전부 세었고, 스냅샷 좌표와 7,916곳 모두 일치했다.
- 이동 시간은 Geofabrik 한국 OSM 파일(자료 기준 2026-10-12)을 OSRM v5.27.1 기본 자동차 · 걷기 프로필로 계산했다. `bus.stopWalkMin`과 `nearest.*.minutes`가 이 값이다.
- 버스 운행 횟수 · 첫차, 시설의 마을 연결, 일부 군 지표, 지역 중심 좌표도 이 좌표나 시간에 간접으로 의존한다.
- Geofabrik은 이 파일을 ODbL 1.0으로 표시한다. OSM 출처 표시는 필수다.

### 법률적 판단 필요

| 쟁점 | 근거 | 영향 |
|---|---|---|
| OSM 마을 좌표 5,007곳이 ODbL 파생 데이터베이스인가 | OSM 재단 지침상 지역 안의 지점을 체계적으로 추출한 경우라 판단 근거가 파생 쪽으로 강하다. 확정은 아니다 | 64곳 직접, 72곳 간접 |
| OSRM 이동 시간이 파생 데이터베이스인가 산출물인가 | 이동 시간 표를 직접 다룬 공식 지침을 찾지 못했다. 분류에 따라 동일 조건 공개 의무가 달라진다 | 72곳 |
| OSM 값과 공공데이터를 나누면 공동 데이터베이스로 인정되는가 | 지침은 한 종류의 값이 전부 OSM이거나 전부 비OSM일 때 독립으로 본다. 좌표 칸은 둘이 섞여 있다 | 72곳 |
| 진도 · 강화 값을 ODbL 파일에 함께 낼 수 있는가 | 상업 금지 · 변경 금지 조건은 ODbL 제공과 충돌할 수 있다 | 2곳 |
| 비OSM 원자료를 ODbL 파일에 넣어도 되는가 | 경로당 좌표 · 시간표 파생값을 OSM 값과 함께 내는 경우에 생긴다 | 후보 28곳 포함 |
| 공공누리 표시가 없는 자료에 저작권법 제24조의2를 적용할 수 있는가 | 문화체육관광부 안내는 기관이 권리를 전부 가진 경우로 설명하고 사전 확인을 권한다. 조문 원문은 읽지 못했다 | 군 누리집 자료 |
| 운영 API에 ODbL 의무가 어디까지 적용되는가 | 운영 API도 같은 좌표 · 시간 값을 제공하므로 정적 배포와 함께 판단한다 | 서비스 전체 |

**검토 권장:** OSM 값을 파생 데이터베이스로 간주해 별도 파일로 ODbL 공개하는 방안이다. 비공개 복사본에서 나눴다가 합친 값은 72개 지역 모두 원본과 같았고, 기본 조건의 판정 · 대안 계산도 같았다. OSM 값 없이는 판정 · 대안 · 지도 점이 동작하지 않으므로, 분리는 의무를 없애는 방법이 아니다. 이 방안의 구현은 PR에 없다.

### 공개 후보

OSM 관련 조건이 해결된다는 전제에서 위 미확인 자료가 없는 지역은 **28곳**이다(담양군은 포털 표시 기준으로 포함): 고창 · 고흥 · 군위 · 남해 · 달성 · 담양 · 무안 · 부안 · 서천 · 성주 · 순창 · 양평 · 완주 · 울릉 · 울주 · 울진 · 음성 · 의령 · 의성 · 장성 · 진천 · 창녕 · 칠곡 · 함안 · 함양 · 함평 · 합천 · 횡성(모두 '군'). 이 28곳도 공개 확정이 아니며, 위 법률 판단과 출처 표시가 끝나야 한다.

### 대체 후보

같은 값인지는 확인하지 못했다. 교체하면 백엔드 재계산이 필요할 수 있다.

- 보은군: 농어촌버스운행표(15053571, 제한 없음) · 청양군: 버스시간표(3078340, 제한 없음)
- 진도군: TS-BIS(제한 없음, 마을 98/98곳에 값 있음). 강화군은 TS-BIS 값이 없다(0/96곳)
- 경로당: 군 · 도 파일(예: 구례 15045230, 해남 15099791, 경상남도 15089076)
- OSM 도로망: 국토교통부 표준노드링크(15025526, 제한 없음)를 검토할 수 있다. 서버 결과와 달라지며, 걷기 경로와 마을 좌표를 대체할 수 있는지는 검증하지 않았다

### 민감정보 검사

`scanSensitive`가 전 지역의 문자열 값과 칸 이름에서 키 · 토큰 · URL · 주민번호 · 전화번호 · 이메일 · 내부 IP · 서버 경로 형태를 찾는다. 72개 지역에서 발견 0건. 문자열 칸은 지역 · 마을 · 읍면 이름, 시설 이름과 종류, 출처 이름뿐이다. 시설 이름 일부에 의원 이름으로 쓰인 사람 이름이 들어 있으나 공개 시설 정보다. 형태 검사이므로 민감정보가 없다는 증명은 아니다.

## 6. 갱신과 공개

```bash
# 비공개 폴더로 수집(기본). 하나라도 실패하면 기존 결과를 그대로 둔다
npm run snapshot
# 파일 검사 + 서버 응답과 값 하나하나 대조
npm run snapshot:verify
```

팀이 공개를 승인하고 통합 파일 방식을 택한 경우:

```bash
# .gitignore의 public/data/snapshot/ 줄을 지운 뒤
node scripts/make-snapshot.mjs --out public/data/snapshot
node scripts/verify-snapshot.mjs public/data/snapshot --live
```

OSM 값을 별도 파일로 나누기로 하면 이 명령을 쓰기 전에 수집 스크립트와 로더를 고쳐야 한다. 일부 지역만 공개하는 경우 지역 코드를 함께 주면 `complete: false`인 스냅샷이 되고 화면에 저장된 지역 수를 그대로 알린다. 자동 갱신은 없다. 서버 자료가 바뀌면 다시 수집해 커밋한다.

## 7. 기능별 지원 범위 (전체 장애 때)

| 기능 | 동작 |
|---|---|
| 랜딩 | 저장 자료로 그린 창녕군 추정값 + 추정 표시. 공문 예시 자리에는 서버가 필요하다는 안내 |
| 지역 선택 · 지표 카드 | 72곳 모두 |
| 진단: 판정, 지도, 필터, 이동수단, 기준 조정 | 모두 브라우저 계산 |
| 마을 카드 | 원자료로 계산하고 그렇게 표시. 서버 응답과 456건 대조 일치 |
| 목표 · 예산 · 공급수단 · 단가 | 모두 |
| 대안 3개, 추천, 지도 배치, 단가 민감도, What-if | 추정 |
| 레포트 | 추정 요약(계산 조건 · 3안 · 배치 · 근거 · 출처 · 기준 시점) + PDF + 공유 링크 |
| 질문 창 | 자료 조회로 바뀜(AI 아님). 공백 · 달성률 · 비용 · 배치 · 안별 차이 · 마을 판정 · 기준 · 출처만 답한다 |

**동작하지 않는 것**

| 기능 | 원인 |
|---|---|
| 서버 최적화(CP-SAT) | 서버 전용. 추정은 근사이며 값이 다를 수 있다 |
| 공문 초안 · 각주 · 문단 편집 저장 | `/api/report`가 만든다. 흉내 내지 않고 추정 요약으로 대신한다. 요약 안의 로컬 편집은 만들지 않았다 |
| AI 질문 · 예시 질문 | `/api/ask` · `/api/examples`. 자료 조회로 대신한다 |
| 바탕 지도 타일 | 백엔드가 아닌 OpenFreeMap을 쓴다. 인터넷이 끊기면 안 보인다. 완전 오프라인(PWA)은 범위 밖이다 |
| 복구 뒤 공유 링크로 연 같은 조건 | 자료가 달라졌으면 결과도 달라질 수 있다 |

## 8. 로컬에서 완전 장애 재현

운영 서버를 건드리지 않고 재현한다. 앱을 빌드할 때 없는 주소를 넣으면 모든 API 요청이 연결 실패한다.

```bash
VITE_API_URL=http://localhost:9 npm run build
```

```bash
cp -R snapshot.local dist/data/snapshot
```

```bash
npx wrangler dev --port 8787
```

`http://localhost:8787`을 시크릿 창으로 연다. 500 · 무응답 같은 다른 장애는 작은 프록시를 앞에 두고 `VITE_API_URL`을 그 주소로 빌드하면 된다. 끝나면 `npm run build`로 `dist/`를 되돌린다(정적 자료가 남지 않는다).

## 10. 유지관리

- 서버 스키마가 바뀌면 `checkRegion`이 수집을 실패시킨다. 새 칸이 앱에 필요하면 `stripRegion`을 확인한다.
- 수집일이 오래되면 화면의 수집일로 드러난다. 이용 조건 표는 자료가 추가될 때 다시 확인한다.
- `scripts/snapshot-all.test.ts`는 스냅샷 폴더가 있을 때만 돈다.
- 출처 표시 의무(공공누리 제1유형 · CC BY · ODbL)는 공개 때 '가정과 출처' 시트와 추정 요약의 출처 목록으로 표시한다. 공개 전에 문구를 팀이 확인한다.
